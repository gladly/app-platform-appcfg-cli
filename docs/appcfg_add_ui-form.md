## appcfg add ui-form

Create a UI form configuration folder and all relevant files

### Synopsis

Creates a "ui/forms/{form name}" folder containing configuration files for a UI form.

UI forms provide a user interface to agents via the "+" menu to execute app platform actions.

The following configuration files will be created:

config.json
-----------
The config.json file contains metadata about the form. This file is populated
with values that you specify via the --action and --data flags. The config.json
file includes:
- "action": Specifies which mutation field from the actions schema will be
  executed when the form is submitted
- "formData": Specifies the data which will be made available for rendering
  the form configuration. Data either comes from a query field from the data
  schema or a query/mutation field from the actions schema.

form.gtpl
---------
This template defines the UI form that will be displayed to agents. The template
must output JSON conforming to the action form configuration defined [here](https://help.gladly.com/developer-tutorials/docs/app-actions-setup#action-fields).

This template has access to the following template data attributes:
- data (form data returned by the query field specified in the --data flag)
- actions (data returned by any action fields specified in the formData array)
- customer (data about the customer associated with the current conversation)

action_inputs.gtpl
------------------
This optional template transforms input values submitted via the form into the
format expected by the action. This template is only needed when there is not a
one-to-one relationship between form.gtpl attr values and action inputs.

For example, a select dropdown might need to provide multiple values (like both
an order number and line item ID) in a single attr field, which then needs to
be split into separate action inputs.

This template receives an object where each field corresponds to one of the attr
values from the form.gtpl inputs. The template must output JSON where each field
corresponds to one of the action's input parameters.

action_result.gtpl
------------------
This template defines how the result of the action should be displayed to the
agent after form submission. The template must output JSON that either conforms to the success or error format defined [here](https://help.gladly.com/developer-tutorials/docs/app-actions-setup#form-errors).

This template has access to the following template data attributes:
- action (the inputs and result from executing the action)

You can customize this template to display specific data from the action
result, format success messages based on the action performed, and include
links or next steps for the agent.

```
appcfg add ui-form {form name} [flags]
```

### Options

```
  -a, --action string     the Mutation field from the actions schema for executing the form action
  -d, --data string       (optional) the Query field from the data schema for populating form data
  -h, --help              help for ui-form
      --input-transform   create an action_inputs.gtpl template for transforming form attributes to action inputs
```
