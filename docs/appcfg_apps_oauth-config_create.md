## appcfg apps oauth-config create

Create an OAuth client credential configuration

### Synopsis


Create an OAuth client credential configuration that Gladly uses to authorize against an external authorization server via the OAuth authorization_code grant.

The auth domain must match the "authDomain" specified in the app's authentication/oauth/config.json file. The name must be unique across all OAuth configurations.


```
appcfg apps oauth-config create [flags]
```

### Options

```
  -d, --auth-domain string     the OAuth authorization domain associated with the client credentials; this is the authDomain specified in the app's authentication/oauth/config.json file
  -i, --client-id string       the OAuth client_id
  -s, --client-secret string   the OAuth client_secret
  -h, --help                   help for create
  -n, --name string            the unique name of this OAuth configuration
```
