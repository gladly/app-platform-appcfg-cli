## appcfg apps check-compatible-config

Check if a configuration is compatible with a new app version

### Synopsis


Check if an existing configuration is compatible with a new major version of an application.

This command verifies that all configuration fields and secrets required by the target version's templates are present in the source configuration. This is useful when planning a major version upgrade to ensure the existing configuration will work with the new app version.

The command takes an app identifier with version (author/appName/version format, e.g., "gladly.com/shopify/v1.0.0") and checks whether the configuration named by --config-name, which was created for that version, has all the fields required by the --to version.

Example:
  appcfg apps check-compatible-config gladly.com/shopify/v1.0.0 \
    --to (-T) v2.0.0 \
    --config-name (-c) "shopify-us"   # which v1 config to check against

If compatible, the output will be:
  Configuration 'shopify-us' is compatible with gladly.com/shopify/v1.0.0 v2.0.0

If not compatible, the output will list the issues:
  Configuration 'shopify-us' is NOT compatible with gladly.com/shopify/v1.0.0 v2.0.0
    - missing field: configuration.apiKey
