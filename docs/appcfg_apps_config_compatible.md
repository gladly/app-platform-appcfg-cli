## appcfg apps config compatible

Check if an existing configuration is compatible with a new major version of the configured application.

### Synopsis


Check if an existing configuration is compatible with a new major version of the configured application.

This command verifies that all configuration fields and secrets required by the target version's templates are present in the source configuration. This is useful when planning a major version upgrade to ensure the existing configuration will work with the new app version.

Example:
  appcfg apps config compatible "shopify-us" --to v2.0.0

If compatible, the output will be:
  Configuration 'shopify-us' is compatible with version v2.0.0

If not compatible, the output will list the issues:
  Configuration 'shopify-us' is NOT compatible with version v2.0.0
    - missing field: configuration.apiKey

```
appcfg apps config compatible {configuration ID | configuration name} [flags]
```
