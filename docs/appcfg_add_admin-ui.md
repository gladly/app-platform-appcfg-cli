## appcfg add admin-ui

Create the admin UI form configuration to enable editing app configuration in the Gladly admin UI

### Synopsis

Creates a "ui/admin/" folder containing the admin UI form configuration.

The admin UI form enables administrators to configure app integration
settings directly from the Gladly admin interface. The form collects
values that populate the app's integration configuration and secrets,
which are then available to templates via .integration.configuration
and .integration.secrets.

If the app has .gtpl templates referencing integration attributes, the
generated form will include a scaffold input section for each discovered
attribute. Otherwise, an empty form is generated that you can populate
manually.

The following configuration file will be created:

form.json
---------
A static JSON file defining the form layout. The form uses the same
schema as action forms documented [here](https://help.gladly.com/developer-tutorials/docs/lookup-adaptor-actions-setup#action-form-response-fields),
with the following differences:

- actionUrl, submitButton, and closeButton are not applicable and
  should be omitted
- Each input section attr must use a "configuration." or "secrets."
  prefix to route the value to the correct storage. For example,
  "configuration.subdomain" stores to .integration.configuration.subdomain
  and "secrets.apiToken" stores to .integration.secrets.apiToken
- Multi-segment dotted paths after the prefix are supported for nested
  structures (e.g. "secrets.credentials.username")

Section types include text sections for static instructional content
and input sections wrapping a text, select, or checkbox input element.

Take a look at other apps' "ui/admin/form.json" files for examples of
how to structure the form for different integration requirements.
