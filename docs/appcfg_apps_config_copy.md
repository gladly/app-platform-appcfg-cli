## appcfg apps config copy

Copy a configuration from one app version to another

### Synopsis


Copy an existing configuration from one app version to another.

This command copies a configuration's settings and secrets to a new configuration on the target app version. It first checks if the configuration is compatible with the target version. If incompatible, you must use the --force flag and confirm the copy operation.

Example:
  appcfg apps config copy "shopify-us" \
    --to-config "shopify-us-v2" \
    --to v2.0.0 \
    --activate

If the configuration is incompatible with the target version and --force is specified, you will be prompted to confirm before proceeding.


```
appcfg apps config copy {configuration ID | configuration name} [flags]
```
