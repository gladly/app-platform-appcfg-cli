## appcfg apps config copy

Copy a configuration from one app version to another

### Synopsis


  Copy an existing configuration from one app version to another.

  This command copies a configuration's settings and secrets from a source app version to a target app version. The command first checks if the configuration is compatible with the target version. If incompatible, you must use the --force flag and confirm the copy operation.

  The command takes an app identifier (format: author/appName/version) and creates a new configuration with the specified name on the target version.

  Example:
    appcfg apps config copy gladly.com/shopify/v1.0.0 \
      --from-config (-f) "shopify-us" \
      --to-config "shopify-us-v2" \
      --to-version (-T) v2.0.0 \
      --activate (-a)

  Flags:
    --from-config: Name of the source configuration to copy from
    --to-config: Name for the new configuration
    --to-version: Target app version (e.g., v2.0.0)
    --activate: Activate the new configuration after creation (default: false)
    --force: Force copy even if incompatible (prompts for confirmation)

  If the configuration is incompatible with the target version and --force is specified, you will be prompted to confirm that you want to proceed.


```
appcfg apps config copy {application identifier} [flags]
```
